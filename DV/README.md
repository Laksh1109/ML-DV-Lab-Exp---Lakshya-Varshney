# Data Visualization (DV) Lab Experiments

This folder contains the eight lab experiments in **Jupyter Notebook (.ipynb)** format, as accepted for the Data Visualization Lab submission.

| File | Experiment |
|---|---|
| Exp_01.ipynb | Getting started: table, bar and line views |
| Exp_02.ipynb | Data cleaning and transformation |
| Exp_03.ipynb | Bar and line charts |
| Exp_04.ipynb | Dashboard filters/slicer concepts |
| Exp_05.ipynb | Geo-visualization with coordinates |
| Exp_06.ipynb | Pie and donut charts |
| Exp_07.ipynb | Heatmap and treemap |
| Exp_08.ipynb | Time-series trends, moving average, trendline and illustrative forecast |

## Requirements
Install dependencies as needed:

`pip install pandas matplotlib seaborn numpy squarify`

The experiments use illustrative sample data within the notebooks, so no external CSV is required. Exp_05 uses a coordinate scatter representation; a true map visual can be created in Power BI or Tableau.
