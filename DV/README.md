# Data Visualization (DV) Lab Experiments

This folder contains Python demonstrations corresponding to the eight DV lab activities.

| File | Experiment |
|---|---|
| Exp_01.py | Getting started: table, bar and line views |
| Exp_02.py | Data cleaning and transformation |
| Exp_03.py | Bar and line charts |
| Exp_04.py | Filtering/dashboard slicer concepts |
| Exp_05.py | Coordinate-based symbol map |
| Exp_06.py | Pie and donut charts |
| Exp_07.py | Heatmap and treemap |
| Exp_08.py | Time-series trend, moving average, trendline and illustrative forecast |

## Requirements
Install dependencies as needed:

`pip install pandas matplotlib seaborn numpy squarify`

Some experiments use illustrative sample data created within the script, so no external CSV is required. Exp_05 is a coordinate scatter representation; use Power BI/Tableau's built-in map visual for a true map.
